Secure File Storage - User Tutorial

Welcome to the Secure File Storage System! This tutorial will guide you through all the features. Follow the steps below to get started.
1

How to Register

Registering is the first step to start using the secure file storage system.

📝 Step-by-Step:
  1. Click on the Register button on the home page
  2. Fill in your details:
    • Username: Choose a unique username
    • Email: Your valid email address
    • Password: Must be at least 8 characters
    • Confirm Password: Re-enter your password
  3. Click the Register button
  4. You'll see a success message and be redirected to login
📋 Example:

Username: johndoe123

Email: john@example.com

Password: ••••••••

Confirm Password: ••••••••

Success: After registration, you'll see "Registration successful! Please login."
Note: Your password is securely hashed and never stored in plain text.
Go to Register
2

How to Login

After registration, you can login to access your secure dashboard.

📝 Step-by-Step:
  1. Click on the Login button
  2. Enter your Username and Password
  3. Click the Login button
  4. You'll be redirected to your dashboard
Success: You'll see "Login successful!" and be taken to your dashboard.
Forgot Password? Contact the system administrator to reset your password.
Go to Login
3

How to Upload Files

Upload files securely. All files are encrypted before storage.

📝 Step-by-Step:
  1. On your dashboard, click the Upload File button
  2. A modal window will appear
  3. Click Choose File and select your file
  4. Click the Upload button
  5. Your file will be uploaded and appear in the file list
Supported Files
PDF, DOC, DOCX, XLS, XLSX, PPT, PPTX, TXT, PNG, JPG, JPEG, GIF
Max Size
100 MB per file
Encryption
AES-256 encryption before storage
Tip: You can upload multiple files one at a time. Each file is encrypted individually.
Success: You'll see "File uploaded successfully!" and your file will appear in the list.
4

How to Share Files

Share files securely with other users with controlled permissions.

📝 Step-by-Step:
  1. From your dashboard, find the file you want to share
  2. Click the Share button next to the file
  3. Enter the username of the person you want to share with
  4. Select permission level:
    • Read Only: Can only view/download the file
    • Read & Write: Can view, download, and modify the file
  5. Set expiration (optional)
  6. Click Share
Tip: The recipient will see the file in their "Shared With Me" section.
Important: You can only share files that you own.
5

How to Download Files

Download your files or files shared with you.

📝 Step-by-Step:
  1. Find the file in your dashboard or shared files section
  2. Click the Download button
  3. The file will be decrypted and downloaded to your device
Tip: Files are decrypted on-the-fly when you download them.
6

How to Delete Files

Remove files you no longer need.

📝 Step-by-Step:
  1. Find the file you want to delete
  2. Click the Delete button
  3. Confirm the deletion when prompted
  4. The file will be removed from the system
Warning: Deletion is permanent. You cannot recover deleted files.
Note: You can only delete files that you own.

Security Features

Learn about the security features that protect your data.

End-to-End Encryption
Files are encrypted before leaving your device
Secure Authentication
Passwords are hashed and never stored in plain text
Access Control
Fine-grained permissions for file sharing
Data Integrity
Files are verified to ensure they haven't been tampered with
Audit Logs
All actions are logged for security monitoring
Expiration
Shared files can have expiration dates
Your data is protected with:
  • AES-256 - Advanced encryption standard
  • RSA-2048 - Secure key exchange
  • SHA-256 - File integrity verification
